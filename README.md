# Audio Visualizer

A real-time 3D audio visualizer with microphone input, file drag-and-drop, bloom post-processing, and keyboard controls.

## Controls

- **T** — Cycle bloom strength (1.5 → 2.5 → 3.5, wraps)
- **F** — Toggle fullscreen
- **M** — Toggle mute

## Usage

- Click to start — microphone input is used by default
- Drag and drop any audio file onto the drop zone (bottom-right) to visualize it instead
